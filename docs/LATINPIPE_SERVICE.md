# LatinPipe REST service

Official service endpoints used by the reproducible syntax pipeline:

- [UDPipe models endpoint](https://lindat.mff.cuni.cz/services/udpipe/api/models)
- [UDPipe process endpoint](https://lindat.mff.cuni.cz/services/udpipe/api/process)

The process endpoint is called with the released `latinpipe-evalatin24-240520` model, presegmented input, tagging, lemmatization, and dependency parsing enabled.
